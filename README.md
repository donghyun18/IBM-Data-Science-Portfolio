# IBM Data Science Professional Certificate Portfolio

This repository contains projects and practical exercises completed as part of the **IBM Data Science Professional Certificate** on Coursera.

The portfolio demonstrates hands-on experience in **data analysis, data visualisation, SQL, machine learning, and Python-based data science workflows**.

---

## 🛠 Technical Skills

- **Programming:** Python, SQL
- **Data Analysis:** Pandas, NumPy
- **Data Visualisation:** Matplotlib, Seaborn, Plotly
- **Machine Learning:** Scikit-learn
- **Tools:** Jupyter Notebook, Git, GitHub
- **Techniques:** Data Cleaning, Exploratory Data Analysis (EDA), Regression, Classification, Model Evaluation, Predictive Modelling

---

## 📂 Projects

### 🌧 Australian Rainfall Analysis
Analysed Australian weather data and applied machine learning techniques to explore weather patterns and predict rainfall.

### 🚗 Automobile Sales Analysis & Dashboard
Performed exploratory data analysis on automobile sales data and developed visualisations and dashboards to communicate trends and insights.

### 🗄️ Chicago SQL Analysis
Used SQL to query and analyse Chicago datasets, applying filtering, aggregation, joins, and other database operations to answer analytical questions.

### 📊 Data Science Capstone
Completed an end-to-end data science project involving data collection, cleaning, exploratory analysis, visualisation, predictive modelling, and model evaluation.

### 🏠 House Price Prediction
Built regression models to analyse housing data and predict house prices using Python and machine learning techniques.

### 📈 Stock Data Extraction
Extracted and analysed financial data using Python, including stock and revenue data, and created visualisations to explore historical trends.
